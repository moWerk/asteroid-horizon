# asteroid-horizon

A precision spirit level and angle meter for [AsteroidOS](http://asteroidos.org/)

Hold your watch flat to see a 2D bubble indicator on a crosshair scale.
Tilt past 60° and it automatically switches to a horizon-line mode showing
roll angle. Tap the bubble to lock your current orientation as zero and
measure relative angles — the bubble turns red to signal delta mode.
Tap the axis lock icons to constrain the bubble to a single axis.
